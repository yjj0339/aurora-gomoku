# 雾弈五子棋部署说明

## 构建

在 `D:\codexAI\aurora-gomoku` 执行：

```powershell
$env:TEMP='D:\codexAI\.runtime\temp'
$env:TMP=$env:TEMP
$env:npm_config_cache='D:\codexAI\.runtime\npm-cache'
& 'D:\codexAI\.toolchains\emsdk\node\24.19.0_64bit\npm.cmd' run build
```

构建后，`dist/` 是唯一需要发布的目录。不要发布其他项目目录，也不要覆盖其他站点。

## 托管要求

- 必须是 HTTPS；否则部分浏览器会限制 WebRTC、剪贴板与 PWA。
- 必须按原样提供 `.wasm` 和 `.data` 文件；`.wasm` MIME 建议为 `application/wasm`。
- 静态主机需允许访问 PeerJS 公共信令服务。
- 单页入口位于 `index.html`，资源使用相对路径，可部署在根域名或子目录。

## 验收清单

1. 首页、六套主题和手机排版正常。
2. AI 第 1—3 档正常落子；第 4—5 档分析面板显示 `Rapfi`。
3. 一台设备创建六位房间码，另一台设备加入并完成双方落子。
4. 完成一局后自动出现在“我的棋谱”，可逐手复盘并导出 SGF。
5. 断网后已访问页面可再次打开；恢复网络后可重新联机。
